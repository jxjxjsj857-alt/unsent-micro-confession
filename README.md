A two-part micro-confession for make.fun's "Unsent: The Micro-Confession Sprint" bounty: a To: line naming who it was meant for, and the unsent line itself, written exactly as it was typed. Running the program writes the confession to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
